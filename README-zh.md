# jzq-marketplace

[English](README.md)

jizhiqiang 的 Claude Code 插件市场。

## 使用方法

```bash
# 添加此市场（一次性）
/plugin marketplace add Jzq/jzq-marketplace

# 安装 jizhiqiang 插件
/plugin install jizhiqiang@jzq-marketplace
```

## 插件列表

| 插件 | 说明 |
|------|------|
| [jizhiqiang](https://github.com/Jzq/opsx-workflow) | 配置驱动的五阶段自动化开发流程，支持阶段检测、操作守卫和危险命令拦截 |
