# jzq-marketplace

[中文文档](README-zh.md)

Claude Code plugin marketplace by jizhiqiang.

## Usage

```bash
# Add this marketplace
/plugin marketplace add Jzq/jzq-marketplace

# Install dev-flow plugin
/plugin install dev-flow@jzq-marketplace
```

## Plugins

| Plugin | Description |
|--------|-------------|
| [dev-flow](https://github.com/Jzq/opsx-workflow) | Config-driven five-phase development workflow with phase detection, operation guards, and dangerous command interception |
